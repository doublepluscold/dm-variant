# Колохвіум · дискретна математика

Вводиш номер варіанту — сторінка рахує `mod*` і показує твої 6 питань разом з повними відповідями.

## Формули варіанту

| Nivel | Питання | Балів |
|---|---|---|
| 1 — означення | `k mod* 23`, `(k+12) mod* 23` | 1 + 1 |
| 2 — приклади | `k mod* 9`, `(k+5) mod* 9` | 1,5 + 1,5 |
| 3 — доведення | `k mod* 7` | 4 |
| 4 — доведення | `k mod* 4` | 6 |

`a mod* b` — звичайний залишок від ділення, але якщо він дорівнює 0, то результат `b`.

## Можливості

- Таймер на 7 хвилин
- Регулювання розміру шрифту
- Друк шпаргалки
- Режим «Усі питання» — повний довідник
- Працює офлайн: встановлюється як застосунок на телефон

## Встановити на iPhone

Відкрити сторінку в **Safari** → «Поділитися» → **«На екран Домівки»**.
Далі відкривається з іконки на весь екран і працює без інтернету.

## Файли

- `index.html` — уся сторінка, без зовнішніх залежностей
- `sw.js` — service worker для офлайн-режиму
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — метадані застосунку
